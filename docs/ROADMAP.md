## Открытые вопросы

- Имя файла compose на сервере сайта: обе спецификации используют `Docker-compose.yml` (с заглавной D). Проверить, что файл называется именно так.
- Время напоминаний (понедельник, 10:00 по Москве) предложено по умолчанию. Можно поменять в любой момент.
